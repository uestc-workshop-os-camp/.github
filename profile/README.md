# 光点计划

对计算机系统充满好奇？

想真正动手做一些更接近底层的东西？

或者已经决定往系统方向深入，希望找到一群能一起学习、讨论和折腾的伙伴？

「光点计划」就是为此而设。

自 2023 年起，我们依托校内多个工作室持续举办「光点计划」，希望为对计算机系统感兴趣的同学提供一条可以真正走下去的学习与实践路径：有明确的学习路线，有需要亲手完成的实验，也有可以一起交流和讨论的伙伴。

今年，**光点计划 IV** 包含两个方向：

* **OS 方向**：从 Rust 开始，逐步进入清华大学 rCore 操作系统实验，完整体验操作系统内核的设计与实现。
* **RDMA 方向**：基于 RDMA101 与 Mooncake 的工程实践，学习 RDMA 的基本原理、编程模型与高性能网络传输。

无论你只是想借这个机会第一次接触系统方向，看看自己是否真的感兴趣；还是已经决定继续深入，希望积累工程经验、认识更多同方向的同学，都欢迎参加。

**没有计算机系统方向的经验也没有关系。**

你不需要在开始之前掌握 Rust、操作系统、RDMA 或各种开发工具。学习使用陌生工具、阅读文档、调试程序、逐步理解复杂系统，本身就是这次活动的一部分。

## 你会得到什么？

光点计划并不只是一份实验。

我们更希望它成为一个可以让你真正开始学习计算机系统，并且持续做下去的入口。

在活动中，你可以：

* 沿着相对完整的路线学习操作系统或 RDMA；
* 通过实际实验，而不是只看资料，理解底层系统如何工作；
* 在校内找到同样对系统方向感兴趣的同学，一起讨论和解决问题；
* 获得举办工作室提供的交流与学习支持；
* 对自己是否适合、是否喜欢系统方向形成更真实的判断；
* 积累后续参与计算机系统项目的基础。

活动结束后，我们会综合实验完成情况、做题得分以及交流 / 面试表现，评选通过与优秀参与者。

表现优秀的同学还可以直接参与举办工作室的招新，并有机会参与之后光点计划的命题、维护和组织。

具体评选规则将在后续说明中公布。

# OS 方向

OS 方向主要分为两个阶段。

我们会先通过 Rust 练习建立足够的语言基础，随后进入 rCore 实验，逐步实现一个真正能够运行的操作系统内核。

## 第一阶段：Rust 学习

时间：九月至十月中旬  

这一阶段主要熟悉 Rust，并完成后续操作系统实验所需要的语言和编程基础。

* 做题链接：即将公布
* 学习与环境配置说明：[第一阶段环境配置与学习资料](https://github.com/uestc-workshop-os-camp/rust-based-os-camp-info/blob/main/2026-info-1.md)

时间：十月中旬至十一月中旬  

在这一阶段，你将进入真正的操作系统实验，逐步接触和实现操作系统中的核心机制。

* 做题链接：即将公布
* 学习与环境配置说明：[第二阶段环境配置与学习资料](https://github.com/uestc-workshop-os-camp/rust-based-os-camp-info/blob/main/2026-info-2.md)

我们强烈推荐有兴趣的同学同时参加：

[2026 春夏季开源操作系统训练营](https://opencamp.cn/os2edu/camp/2026spring)

# RDMA 方向

RDMA 方向面向希望了解高性能网络、分布式系统通信以及 AI Infra 的同学。

我们采用 [Feng Ren](https://renfeng.org) 编写的 [RDMA101](https://renfeng.org/RDMA101/) 作为主要学习材料。

RDMA101 来源于 Mooncake Transfer Engine 的实际工程经验，旨在为希望理解、使用、运维或进一步开发 RDMA 系统的读者提供了一条相对完整的学习路径。

你将逐步接触 RDMA 的基本原理、编程模型，以及实际高性能数据传输系统中的关键问题，并通过后续实验将这些概念真正跑起来。

* 教程：[RDMA101](https://renfeng.org/RDMA101/)
* 实验：即将开放
* 实验与环境说明：后续公布

# 现在就可以开始

不需要等到宣讲会。

如果你现在已经看到这里，就可以直接选择感兴趣的方向，开始阅读对应的学习资料和环境配置说明。

下面的时间安排主要用于标记建议学习进度和最迟开始时间，活动整体进度相对灵活，最终评选会综合参考实验完成情况、做题得分以及面试表现。

希望每个人最终获得的都不只是一个排名，而是真正学会了一些东西，并找到自己愿意继续深入的方向。
